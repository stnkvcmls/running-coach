Running Coach · UI Redesign Study · v1

Nothing OS for a training app.

Dot-matrix, hairline, deliberately un-decorative. The Nothing look is carried by geometry and type, not hue — so it works with two different palettes, and you can flip every screen below between them: signal red, which spends colour once per screen, or app inks, which keeps the palette already in globals.css but moves it off surfaces onto strokes, labels and chart series. Below: the token set, seven screens, the component sheet, and a direct mapping from what the app renders today.

Both toggles apply to every screen below

Two strategies, one geometry. Signal red spends colour once per screen. App inks keeps the palette you already have but demotes it to strokes, dots and labels — never a filled surface. Toggle at the top of the page.

Dot-matrix numerals

Every headline metric renders on a 5×7 perforated grid — unlit dots stay visible at 10%, the way a Glyph panel reads when it's off. Body copy stays in a plain grotesque.

Flat surfaces, zero shadow, 1px hairlines instead. Elevation is communicated by border contrast, not blur. Perforated dot fills replace gradients.

04 What changes current app → Nothing OS treatment
Token / elementTodayProposed
--bg / --bg-card #0f0f1a navy, #1a1a2e cards, drop shadows on every card True #000 with #0B0B0B tiles and 1px #232323 hairlines. Shadows removed — --shadow-sm/md become none.
--accent #6c5ce7 purple on buttons, chips, links, rings, nav — everywhere Both ink sets: ink (#FFF/#000) carries every default state, so buttons, chips and links stop being purple. Signal red repoints --accent to #D71921; app inks keeps #6c5ce7 but rations it to alerts, today's marker and the nav glyph.
Workout colours Six hues — easy/tempo/interval/long/race/cross/strength — on fills, borders and text Signal red: one ink plus fill weight; colour-blind-safe but the plan loses a scanning cue. App inks: all six survive, moved off surfaces and onto the type label + icon stroke only. Same geometry either way.
Numerals .stat-value — system sans, tabular-nums 5×7 dot-matrix rendering for hero metrics only (readiness, distance, pace, adherence, PB times). Unlit dots stay at 10% opacity.
Typography -apple-system stack throughout Monospace-grotesque for all labels, values and nav (uppercase, .16–.26em tracking); plain sans reserved for briefing and coach prose.
BottomNav Purple icon + label on active tab Ink icon plus a red glyph bar above the active tab — the light-strip cue from the phone's Glyph interface.
ScoreRing Solid arc, score in sans, colour by band Perforated dotted arc, dot-matrix score, band expressed as arc length and one mono sub-label rather than hue.
Skeleton / spinner Shimmer gradient, purple-topped spinner Perforated blocks; the spinner becomes a rotating dot ring on the same 5×7 grid.
Radii 12 / 8 / 6 px 26 tile · 20 card · 12 icon · pill controls. Larger, squarer squircles read as OS surfaces.
Chart palettes 8 hardcoded constants in chartTheme.ts + colorMap/SPORT_COLORS; none read CSS vars Signal red needs all of them rewritten as skin-aware functions and a client-side override for API-supplied zone_color. App inks needs none of it — the constants stay exactly as they are.
Light theme #f5f5f7 grey-blue with the same purple accent Nothing's white mode: pure #FFF, #F4F4F4 surfaces, black ink, identical red. Toggle at the top of this page shows both.
Scope note. This is a visual study only — nothing in frontend/src was modified. Every screen above is redrawn from the real component tree (TodayView, TodayHero, PlanView, ChatView, ActivityListItem, TrendsView, ActivityDetailView, BottomSheet) with the same data shapes the API returns, so the mapping table is directly actionable: the bulk of it lands in styles/globals.css tokens plus utils/colors.ts and utils/chartTheme.ts. The dot-matrix numeral renderer is the one genuinely new primitive and would ship as a small <DotMatrix> component.

On the two ink sets. The Nothing look is carried by geometry, not hue: flat black/white surfaces, 1px hairlines, no shadows, mono uppercase micro-labels, perforated fills and 5×7 dot-matrix numerals. All of that is orthogonal to the palette — which is why app inks reads as Nothing OS while keeping every colour the app already ships. The rule that makes it work: colour never touches a surface, only strokes, dots, type labels and chart series. Sample data is illustrative.
